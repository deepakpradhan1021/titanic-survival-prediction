# Titanic Survival Prediction

A machine learning project that predicts whether a passenger survived the Titanic disaster.

## Project Overview

This project uses the Titanic dataset from Kaggle to build a machine learning model for survival prediction.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

Dataset: Kaggle Titanic

The dataset contains information about passengers such as age, gender, passenger class, fare, and survival status.
